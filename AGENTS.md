## Project rules
- Pages consume data only through `src/services` (contracts + factory in `src/services/index.ts`); never import `src/services/mock/*` from UI, so the mock can be swapped for a real backend in one place.
- Domain types/rules live in `src/domain/` with no React deps; money is integer COP, dates ISO, formatting via `src/lib/format.ts`.
- Each job has a separate route tree wrapped by `AppShell`; demo services repeat role/scope checks, and future real authorization must be server-side.
- Mock services compose rental and business contracts in one factory; UI never accesses mock persistence directly, so a future adapter can replace it without rewriting pages.
- Route sales use a serialized commit and IndexedDB operation queue before stock changes; reconciliation is shared domain logic for preview and persistence to prevent contradictory totals.
- All calendar grouping uses the domain Bogotá date helper; payroll estimates are pure domain calculations that leave missing parameters unresolved rather than invent legal rates.
- PWA caching is generated by vite-plugin-pwa; its single browser wrapper refuses development, preview, iframe, and kill-switch contexts to avoid stale previews.
